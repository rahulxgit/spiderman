# Spider-Man — The Web-Slinger

A fan-made visual field guide to Spider-Man's origin, code, and legacy. The original single-file page has been rebuilt as a responsive landing page with a comic-inspired editorial layout.

## Run locally

This is a dependency-free static site. From the project directory, start any static file server:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## What's included

- Responsive desktop and mobile layouts with a full-screen navigation menu
- Dark ink, paper, and crimson visual system with web-inspired graphic details
- Scroll-reveal transitions and active section navigation
- Interactive gallery lightbox with keyboard and backdrop closing
- Reduced-motion support and semantic, accessible HTML
- Local image assets so the page does not depend on the original expiring image URLs

## Project structure

```text
├── index.html       # Page structure and content
├── style.css        # Visual system and responsive layout
├── app.js           # Navigation, reveal effects, and gallery lightbox
└── assets/          # Local visual assets
```
